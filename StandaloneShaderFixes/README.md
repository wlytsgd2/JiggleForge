# JiggleForge Global Jiggle ShaderFix

这是 JiggleForge 使用的游戏内全局 VS 变形运行时源文件。桌面应用负责安装运行时、管理受支持的顶点着色器替换，并原地适配替换 Mod。

## 安装

应用会把勾选的全部全局拖动键同时写入游戏运行时和 `WheelBridge.txt`。按下其中任意一个都能拖动；WheelBridge 运行期间修改按键后，会在下一次滚轮输入时自动重新读取配置。

在 JiggleForge 的“运行环境”页面完成状态检查、安装、更新、卸载和 WheelBridge 控制。安装操作会：

- 将 `JiggleForge.ini` 和 `JiggleForge` 复制到 `Mods\JiggleForgeShaderFix`。
- 将应用中选择的全局拖动键写入主运行时 INI 的受控配置段。
- 将支持的 `hash-vs_replace.txt` 写入 ZZMI 的 `ShaderFixes`。
- 在覆盖已有同名着色器前创建 `.pre_jiggleForge_backup` 备份。

## 卸载

在 JiggleForge 的“运行环境”页面点击“卸载运行环境”，然后回到游戏按 `F10`。应用会移除 JiggleForge 文件，并恢复安装前备份的同名着色器。

## 运行时能力

- 使用应用中选择的任意一个全局拖动键拖动。
- 鼠标滚轮控制冻结屏幕法向上的独立深度坐标；深度不旋转拖动方向，也不缩短鼠标产生的屏幕内位移。
- 正深度沿按下时屏幕平面朝向摄像机，负深度进入屏幕；方向不依赖所选三角形自身的表面法线。
- 在按下拖动键的瞬间冻结屏幕方向；保持拖动期间旋转摄像机不会改变本次变形使用的世界方向。
- 使用世界坐标半径计算影响范围。
- 保留 ZZMI Skin、替换 Mod 的最终 VB0/IB、索引范围和绘制流程。
- 同一真实游戏 Draw 内按 pre-Skin、post-Skin、精确适配范围的质量选择候选；不同 Draw 之间按屏幕深度选择最靠前的可见表面，避免替换身体截走未修改前景部件的鼠标命中。
- 同步主体、轮廓及近摄像机特殊 pass 的变形状态。
- 支持由 JiggleForge 生成的独立 Draw 状态、依赖图、纹理 Mask 和 Draw 识别器。

## 限制

- 只处理已收录的游戏 VS；游戏更新后若 hash 或常量缓冲布局变化，需要更新运行时。
- 自行替换游戏 VS 且与本运行时不兼容的 Mod 可能无法处理。
- 请使用 JiggleForge 适配 Mod，不再使用旧版独立补丁器或 `Builds` 工作流。
