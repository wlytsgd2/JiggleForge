# JiggleForge 品牌图标

图标主体是向右上方拉伸的银色软体，直接表现 JiggleForge 的拖拽与柔性变形功能。

## 文件

- `JiggleForge-source.png`：用户提供的原始图片，保留用于追溯设计来源；原图中的棋盘格是实际像素而非透明通道。
- `JiggleForge-1024.png`：清除棋盘格后生成的透明背景应用图标主图。
- `JiggleForge-16.png` 至 `JiggleForge-512.png`：为 Windows 界面和快捷方式导出的常用尺寸。
- `JiggleForge.ico`：包含 16、24、32、48、64、128、256 像素的 Windows 多尺寸图标。

应用、EXE 和快捷方式均使用这套导出资源。重新导出时应从 1024 像素主图生成全部尺寸，避免不同尺寸的设计不一致。
