# JiggleForge 0.1.26-beta.2 · 本地测试版

本包尚未发布到 GitHub，不属于正式版自动更新。

## 使用

1. 解压到新文件夹，运行根目录的 `JiggleForge.exe`。
2. 完全退出游戏。在设置里确认 ZZMI 路径，点击安装／更新全局运行时，然后重启游戏。不能只按 F10：旧的替换着色器及资源缓存可能仍留在进程内。
3. 设置里的“使用骨骼权重”默认开启。切换后点击旁边的应用按钮，再完全重启游戏。

开启：原距离场 × 当前顶点的共同骨骼权重。两种模式均使用各自物理参数中的“最大位移”，不再附加 0.03 上限。不旋转骨骼，不需要角色表，不修改角色 Mod。

关闭：恢复原 JiggleForge 的空间场和原最大位移参数，不运行骨骼搜索或准备新增逐模型权重读取视图。仍保留鼠标隐藏时休眠／取消交互、CB 子区域修复和原有校准逻辑。因此不是逐字节恢复旧运行时，也不声称等同卸载。

## 实验室

- 全局默认参数页、Mod／组物理参数页均有“在实验室预览”，带入当前编辑的 15 个参数和骨骼开关。也可直接打开 `App/Lab/index.html`。
- 左键拖动、点按拍打、抓住时滚轮改变深度；右键旋转，未抓取时滚轮缩放。支持参数 JSON 导入／导出。
- 网页只做预览，不修改应用或游戏设置。骨骼开关不改变最大位移；两种模式共用设置中的上限。
- 空间公式与运动公式按运行时移植，运动使用固定 60 Hz。测试模型保持静止；不复现动画、游戏帧率、拾取延迟、Mod mask／分组／依赖和校准。骨骼来源使用同模型流中距离抓点最近的顶点，保留 0.04 拒绝阈值，不把测试模型的骨骼编号当作所有角色的编号。

## 兼容与测试范围

不改变既有适配 Mod 的接口。老 Mod 不需要仅为此开关重新适配；已有物理参数不会被重置。切回正式版前也应退出游戏，再使用正式版应用更新全局运行时。

保留原诊断功能，默认关闭黄色诊断文字。本版经过着色器编译、输入／输出签名、独立 GPU 数据回放、开关和实验室测试；这不等同所有角色／设备均已在游戏中验证。
