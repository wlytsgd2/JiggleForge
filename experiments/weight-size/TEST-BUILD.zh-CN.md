# JiggleForge v0.1.26-beta.3 · 权重区域尺寸测试

这是 GitHub 预发布版，不是正式版，也不会通过正式版自动更新推送。
在已验证的 WeightSize r1 运行时上打包应用，未修改其变形算法。

## 安装和使用

1. 解压完整应用包到新文件夹，运行根目录 `JiggleForge.exe`；保留 `App` 和 `Runtime` 的目录结构。包内自带 .NET 和 Windows App Runtime。
2. **完全退出游戏**，备份原运行时到 ZZMI 目录之外。请勿同时安装两个 JiggleForge 运行时。
3. 在应用设置中确认 XXMI 实际使用的 ZZMI 路径，安装／更新全局运行时，再启动游戏。不能仅按 F10。
4. 开启“使用骨骼权重限制变形”。显示鼠标后按 X 或左键拖动，F7 总开关；已有键位设置仍会保留。

仅想手动安装运行时，可下载单独的 `JiggleForge-manual-v0.1.26-beta.3.zip`，按包内说明操作；两个包包含相同的 51 个运行时源文件。应用包另外提供滚轮桥接程序，手动包不含可执行文件。两种安装方式任选其一。

## 这次测试什么

- 抓取时选取抓点最大合并权重的骨骼，按对应顶点权重分布估计尺寸；不旋转骨骼。
- 有效尺寸最高 **0.04**，共用参考尺寸 **0.03**。影响半径、运动位移随尺寸同比例缩放。
- 基础最大位移最高 **0.05**，之后仍随尺寸缩放，默认参考尺寸下最高约 **0.0667**，不是最终绝对上限 0.05。
- 已有更小的基础上限保留。大于 0.05 的值只在运行时解码时限制到 0.05，不改写已有 Mod 参数文件。
- 尺寸统计只在新抓取绑定确认时执行；拖动及回弹期间复用。不新增 GPU 资源缓冲或 Dispatch，但抓取时仍有额外统计开销。
- 骨骼开关关闭时，尺寸估计也关闭；使用原距离场，但本测试的基础位移限制仍然有效。

不重置已有参数，不要求重新适配 Mod，不修改 XXMI。应用内的旧参数实验室仍为基础 v26 预览，**不模拟本版尺寸缩放和 0.05 限制**，不能把它当成本版逐点相同的结果。

## 测试和回退

重点比较不同大小角色、同部位中央／边缘、不同场景、原版和已适配 Mod，以及首次抓取是否停顿。抓取位置换到另一根主骨骼时，估计尺寸仍可能改变；本方法不是解剖识别或防穿透模型。

要回退：退出游戏，使用正式版应用更新全局运行时，或按手动包说明恢复备份。不要直接删运行时后留下适配 Mod 的引用。测试包与正式版应用共用用户设置和历史记录；在测试包里主动保存的设置也会影响之后的正式版。

已做着色器编译、GPU 回放及应用安装流程验证；不是所有角色／环境的游戏内效果保证。一般使用说明见 README，本文件中的测试差异优先。
