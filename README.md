# JiggleForge

JiggleForge is a Windows desktop tool that adapts XXMI/3DMigoto replacement Mods into configurable, mouse-driven world-space deformation Mods.

It provides a visual workflow for Draw discovery, grouping, dependency graphs, masks, physical parameters, runtime installation, and wheel-based depth input. The application edits the selected Mod in place and stores the project configuration in `JiggleForge.txt`.

> This repository is being prepared for its first public release. Check the Releases page for the latest self-contained package.

## What it does

- Adapts a replacement Mod without requiring the original Mod folder after the first import.
- Gives every adapted Draw a stable state identity and configurable group membership.
- Supports explicit group dependencies, including transitive influence.
- Uses world-space picking and deformation so the same motion state can be reused by body, outline, transparent, depth, and material passes.
- Preserves original normals, tangents, and lighting at zero displacement and updates the surface frame from the deformation field while dragging.
- Supports DDS masks; missing masks use a weight of `1.0`.
- Provides per-group physics, global defaults, multiple drag keys, wheel depth control, and an optional in-game Draw inspector.
- Installs and checks the global runtime and supported game VS replacements from the application.

## Requirements

- Windows 10 version 19041 or newer, or Windows 11.
- XXMI/3DMigoto and a supported game installation.
- A self-contained JiggleForge release package. The package includes the .NET runtime and does not require a separate .NET installation.

The supported VS hash matrix is documented in [Shader hash matrix](docs/development/shader-hash-matrix.zh-CN.md). A game update can change these hashes; if a pass is no longer recognized, re-run FrameAnalysis hunting and update the matrix before adapting Mods.

## Quick start

1. Download and extract the latest self-contained release to a normal writable folder.
2. Start `JiggleForge.exe`.
3. Open **Runtime** and select the ZZMI root directory.
4. Choose **Install or update runtime**, then return to the game and press `F10`.
5. Drag a replacement Mod folder into JiggleForge, or select it with the folder picker.
6. On the Draw page, review the detected Draws, groups, masks, and the inspector toggle.
7. Open **Physics** or **Dependencies** if you want to customize them, then choose **Apply configuration**.
8. Return to the game and press `F10` to reload the generated resources.
9. Hold one of the configured drag keys over the model. Start WheelBridge from **Runtime** if you want wheel-controlled depth.

For a detailed walkthrough, see [Quick start](docs/user-guide/quick-start.md) or [中文快速入门](docs/user-guide/quick-start.zh-CN.md).

## Existing adapted Mods

An existing Mod generated by an earlier JiggleForge build should be opened once with the current application and applied again. This regenerates its private runtime resources with the current schema and command names. Keep a backup of a working Mod before applying a major runtime update.

## Project layout

- `app/JiggleForge` — WinUI 3 desktop application.
- `src/JiggleForge.Core` — project scanning, configuration, patching, and runtime generation.
- `src/JiggleForge.WheelBridge` — wheel input bridge.
- `StandaloneShaderFixes` — global runtime and supported VS replacement sources.
- `tests` — unit, contract, and CPU/GPU parity tests.
- `docs/user-guide` — user-facing documentation.
- `docs/development` — architecture, configuration, hash matrix, and implementation notes.

## Build and test

```powershell
dotnet test JiggleForge.slnx --configuration Release
dotnet build app/JiggleForge/JiggleForge.csproj -c Release -p:Platform=x64
powershell -ExecutionPolicy Bypass -File tests/shaders/ValidateGpuRuntime.ps1
```

To create a self-contained x64 package:

```powershell
dotnet publish app/JiggleForge/JiggleForge.csproj `
  -c Release -p:Platform=x64 -r win-x64 --self-contained true `
  -o artifacts/JiggleForge
```

The package output is intentionally ignored by Git. Release archives and checksums are published separately.

## Scope and provenance

JiggleForge's input handling, state model, motion solver, world-space deformation field, application, and test suite are maintained as an independent implementation. Game-derived VS replacement sources are kept separate from the application code and are documented in [the provenance note](docs/development/provenance-audit.zh-CN.md).

JiggleForge is an independent community tool. It is not affiliated with the game publisher, XXMI, or 3DMigoto. Users are responsible for following the rules of the game, the Mod author, and their distribution platform.
