# 中文快速入门

## 1. 安装全局运行时

1. 解压 JiggleForge 自包含版本。
2. 打开“运行环境”。
3. 选择 ZZMI 根目录，通常是包含 `Mods` 和 `ShaderFixes` 的文件夹。
4. 点击“安装或更新运行时”。
5. 回到游戏按 `F10`。

运行时是全局安装的；每个 Mod 仍需要单独适配。

## 2. 适配 Mod

1. 将替换 Mod 文件夹拖入应用。
2. 第一次导入会扫描 Mod 的 INI，并在 Mod 文件夹内生成 `JiggleForge.txt` 和私有运行资源。
3. 检查 Draw 列表。只有在确实需要辨认部位时才修改别名，原始 Draw 身份不会改变。
4. 将 Draw 放入分组，在依赖关系页面连接需要共同变形的组。
5. 如果只想让 Draw 的一部分变形，指定 DDS Mask；没有 Mask 时默认权重为 `1.0`。
6. 修改全局默认值或各组独立物理参数。
7. 点击“应用配置”。

原 Mod 的绘制命令会保留在源 INI 中。JiggleForge 只追加生成的运行区块；生成后不再要求原 Mod 位于首次导入的位置。

## 3. 游戏内测试

1. 回到游戏按 `F10`。
2. 按住配置好的拖动键，在可见的不透明身体部位上拖动。
3. 鼠标移动控制冻结屏幕平面内的变形。
4. 需要滚轮控制深度时，在“运行环境”页面启动 WheelBridge。
5. 只有定位 Draw 时才开启 Draw 检测器，正常使用时建议关闭。

同一次拖动过程中旋转摄像机不会重新计算拖动方向。松开按键后重新拖动，才会使用新视角。

## 4. 打开已有项目

打开含有 `JiggleForge.txt` 的文件夹即可恢复项目配置。安装新版全局运行时后，建议重新点击一次“应用配置”，让 Mod 的生成区块使用当前运行时契约。处理旧版项目前请先备份。
