# 故障排查

## Mod 没有变化

- 确认适配后的 Mod 在 ZZMI 中已启用。
- 修改设置后回到游戏按 `F10`。
- 确认全局运行时安装在实际启动游戏的 ZZMI 根目录中。
- 如果游戏刚更新，先刷新 VS hash 对照表，再重新生成运行时资源。

## 只有部分区域有反应

拾取器只能选择被允许的主画面 pass 绘制的几何体。检查 Draw 检测器和场景白名单。半透明、轮廓、阴影以及替换 pass 可能需要单独登记或明确排除。

如果不可见的替换网格仍在绘制，它可能抢先通过拾取测试。可以关闭对应 Draw，或使用与可见部件匹配的 Mask 和依赖图。

## 模型破碎、变白或闪烁

先关闭适配 Mod，确认原 Mod 本身正常。然后检查每个 Draw 的索引范围、顶点布局和索引缓冲是否保持原值。不要把其他角色、LOD 或场景的配置直接复用；资源变化后应从原 Mod 重新适配。

## 拖动位置发生偏移

先检查场景和 pass hash。角色菜单、街区等场景可能使用不同的投影或深度约定。对出现偏移的场景重新进行 FrameAnalysis hunting，并在修改物理参数前更新 hash 对照表。

## Mask 看起来没有生效

Mask 必须放在生成后的 Mod 文件夹中，并使用预期的 DDS 通道和布局。红色通道黑色为 `0.0`，白色为 `1.0`；缺失或无效文件会按设计回退为 `1.0`。Mask 只控制变形权重，不改变三角形拾取范围。

## 滚轮输入没有作用

在应用中启动 WheelBridge，并在 Windows 提示时授予所需权限。确认全局拖动键和 WheelBridge 使用同一个运行时目录。安装或更新桥接程序后重启游戏。

需要诊断时可在应用中开启 Draw 检测器；正常游玩前如果不需要覆盖层，可以关闭它。
