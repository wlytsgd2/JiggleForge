# 配置说明

`JiggleForge.txt` 是项目唯一的可编辑配置源。生成的 INI 区块、Mask、Draw 检测器资源和运行时绑定都由它生成。

## Draw 与分组

- Draw 表示原 Mod 中的一条实际执行绘制路径。
- 组为其中一个或多个 Draw 提供共同的物理参数。
- `OriginalParts` 是原版与未适配部件使用的固定默认通道组（`StateIndex 0 / ObjectID 1`），并且始终启用。
- 关闭某个 Draw 的变形后，它仍可被检测器显示，但不会注册运动状态，也不会读取组依赖。

## 依赖关系

`A -> B` 表示由 A 拥有的拖动也会影响 B。应用会把依赖图编译为去重后的状态列表；循环会在生成前拒绝或合并。

需要精确选择组名时使用边列表；需要整体理解关系时使用互动图。

## Mask

DDS 的红色通道是变形权重：

- 黑色 = `0.0`，不变形；
- 白色 = `1.0`，完全变形；
- 灰色 = 部分变形；
- 缺失或无效 Mask = 使用 `1.0` 默认值。

Mask 必须符合该 Draw 使用的顶点/UV 布局。Mask 不会改变鼠标拾取哪些三角形。

## 物理参数

最常调整的参数包括：

- 影响半径和衰减：控制空间范围；
- 强度和拖动比例：控制鼠标响应；
- 最大位移：限制世界坐标位移；
- 按住/松手频率与阻尼：控制弹簧手感；
- 松手冲量：控制拖拽松手时继承的运动，也控制短按拍打的力度；
- 滚轮步长及最小/最大深度：控制第三维滚轮输入；
- 体积响应：控制周围体积保持效果。

组参数会覆盖该组 Draw 使用的 Mod 默认参数。修改后请先保存，再回游戏按 `F10`。

在有效三角形上按下并于 `0.20` 秒内松开，且鼠标移动不超过 `10` 像素时，运行时会把它识别为拍打。拍打先沿所选三角形法线的反方向压入，再使用当前组的松手弹簧和阻尼回弹。
