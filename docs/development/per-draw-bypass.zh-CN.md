# 单 Draw 完全旁路接口

JiggleForge 提供一个共享 IniParams 标志，供其他 Mod 让指定 Draw 绕过变形，并阻止鼠标穿过它选中后方模型：

```ini
z112 = 1
drawindexed = 12345, 0, 0
z112 = 0
```

`z112` 是 `IniParams[112].z` 的 INI 快捷写法，对应共享 `t120` 参数纹理中第 112 项的 z 分量；它不是 VS 或 PS 的资源槽位编号。

- `0`：正常执行 JiggleForge，也是默认值。
- `1`：目标 Draw 不接受变形，也不成为鼠标拾取结果。

调用方必须在目标 Draw 前立即设置 `z112 = 1`，并在 Draw 后立即恢复 `z112 = 0`。JiggleForge 不会自动复位，因为外层游戏 ShaderOverride 可能早于替换 Mod 内部真正的 Draw 执行；在外层复位会落在错误的边界。

## 运行方式

顶点着色器会尽早检查 `z112`。值为 `1` 时，会跳过 JiggleForge 的屏幕基向量构造、Mask 采样、状态读取、位移和法线重建等附加计算，只保留游戏原 VS 的工作以及读取旁路标志所需的极少开销。

像素着色器不会简单地忽略这个 Draw。它仍让目标表面参加游戏原有的光栅化和深度测试：

- 若表面没有覆盖鼠标像素，什么也不写。
- 若表面覆盖鼠标像素并通过深度测试，就把 JiggleForge 的拾取数据清零。
- 因此前面的旁路表面会挡住后方模型，但自己不会被选中。
- 若目标 Draw 使用特殊深度状态，例如不写深度、始终通过深度测试、使用另一张深度缓冲或之后清空深度，则结果可能不同。

## 调用边界

一个命令列表含有多个 Draw 时，应分别包围每个需要旁路的 Draw。复位语句必须位于不会被条件分支跳过的位置：

```ini
if $draw_component
    z112 = 1
    drawindexed = 12345, 0, 0
    z112 = 0
endif
```

这个接口与应用中的“关闭 Draw 变形”开关相互独立。现有开关仍保留原有行为：Draw 可以被检测，但本身不产生或接收变形；`z112` 则用于完全旁路 JiggleForge，并让该表面阻挡对后方几何的拾取。
