## 运行时职责

- `26214fb5eedfcbdd` 和 `c280f6945b23a42a` 是主体 pass，参与鼠标拾取并接收变形。
- 其余表内 hash 只接收主体已经生成的变形，不参与鼠标拾取。
- `ad24b1c214866fd7` 是镜头靠近时额外执行的透明度过滤/深度预处理。它与 `26214fb5eedfcbdd` 绘制相同身体几何，因此必须同步变形。
- 表中的 `—` 表示当前 FrameAnalysis 中没有发现需要适配的对应 pass。

同一个 VS hash 出现在多个场景中，只说明当前版本复用了相同的着色器字节码，不保证游戏更新后仍然共用。即使 hash 相同，不同场景也可能使用不同的渲染目标尺寸和坐标映射。`c280f6945b23a42a` 当前由 `JiggleForge.ini` 根据渲染目标宽高比选择独立拾取 profile。

## 兼容与排除项

- `a6030ebb8c49cf02` 是旧版角色选择界面的轮廓 VS，当前版本已经移除。
- `1b6d08acd285344c` 已确认是全屏合成绘制，不是角色几何，不能加入变形表。
- `627842b0bee31f24` 是菜单场景的投影阴影绘制，当前不处理。

## 游戏更新后的核对方法

1. 分别在六种场景中进行 FrameAnalysis。
2. 逐列 Hunting 不透明主体、轮廓、半透明主体、半透明附加 pass 和深度 pass。
3. 记录完整 16 位 VS hash，不只记录前几位。
4. 比较新旧 VS 的常量缓冲布局、输入输出签名和投影计算。
5. 更新替换着色器后，分别验证鼠标位置、变形位置、轮廓、半透明材质和近距离深度。
6. 即使多个场景仍共用一个 hash，也要分别验证其渲染目标比例和拾取坐标。
