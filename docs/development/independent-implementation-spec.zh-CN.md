# JiggleForge 独立实现技术规格

## 历史来源与本文范围

JiggleForge 的研究起点来自 Rayvich 开发的 RZMenu，以及他对《绝区零》交互式模型变形技术的早期探索。本文只规定 JiggleForge 当前代码的独立实现边界，不用于否认或替代这段历史来源。完整记录见 [ACKNOWLEDGEMENTS.md](../../ACKNOWLEDGEMENTS.md)。

## 目标

JiggleForge 将任意受支持角色及替换 Mod 的 Draw 映射为可独立配置、可组合依赖的世界空间柔性形变状态。

运行时必须满足：

- 原版角色和适配 Mod 使用同一套运动与形变模型；
- 每个 Draw 或组拥有稳定的状态身份；
- 多个渲染 pass 只复用结果，不重复争抢输入；
- 零位移严格保留原始位置、法线、切线和历史位置；
- 缺少 Mask、局部参数或适配信息时采用明确的安全默认值；
- 无效输入不得产生 NaN、无穷值、越界写入或破碎模型。

## 独立实现边界

本实现根据产品行为、公开的图形学与物理公式、游戏导出的原始 Shader，以及 JiggleForge 自己的测试构建。

不得以 RZMenu 早期参考实现的下列内容作为当前代码的实现模板：

- HLSL 函数体、常量布局或状态编码；
- INI 命令顺序、资源槽位组织或命名；
- 拾取、积分、形变和重置的逐句控制流；
- 注释、文档或私有工具脚本。

允许使用不具备来源特异性的基础事实，例如 HLSL 语法、D3D11 资源查询、重心坐标、弹簧阻尼公式、正则化位移场和由游戏自身导出的 VS 指令。

## 数据契约

### 输入帧

- 鼠标像素坐标；
- 视口尺寸；
- 拖动键状态；
- 两个方向的滚轮序号；
- 受限的帧间隔。

### 抓取记录

- 有效位、ObjectID、generation 和来源 Draw；
- 按下时鼠标坐标；
- 三角形重心的世界坐标；
- 抓取时冻结的屏幕右/上世界方向；
- 三角形序号、三个真实 IB 索引和重心权重；
- 深度、候选优先级和流水号。

### 组参数

每个状态使用五条 `float4`：

- 身份与 schema；
- 半径、强度、衰减和体积响应；
- 拖动比例、最大位移和目标跟随时间；
- 按住/松手频率与阻尼；
- 松手冲量、滚轮深度步长与范围；
- 鼠标轴符号和有效位。

### 运动状态

每个状态使用七条 `float4`：

- 当前世界位移和有效位；
- 世界速度和休眠计数；
- 抓取锚点和所有者；
- 冻结屏幕右方向和来源 Draw；
- 冻结屏幕上方向和深度目标；
- 过滤后的目标和滚轮序号；
- 上一目标、按住状态与 capture generation。

## 输入控制

- 按下边沿只接受当前帧有效拾取。
- 开始拖动时冻结抓取位置与屏幕基向量。
- 保持期间不得因摄像机旋转重新解释已有位移方向。
- 松手边沿只触发一次。
- 同一抓取 generation 在保持期间不得被其他 pass 替换。
- 半透明和只接收 pass 不产生拾取候选。

## 运动模型

目标位移由三部分组成：

1. 鼠标水平像素差映射到冻结的屏幕右方向；
2. 鼠标垂直像素差映射到冻结的屏幕上方向；
3. 滚轮累积映射到冻结屏幕法向量。

目标经过可选的指数跟随滤波，再由显式速度状态和隐式弹簧阻尼积分。帧间隔限制在安全范围内；所有用户参数在使用前检查有限性并夹紧。

松手时可以继承有限比例的目标速度。达到最大位移时移除继续向外的速度分量。静止达到阈值后将状态清零休眠。

## 形变模型

对当前世界顶点与抓取锚点计算径向权重：

- 半径外严格为零；
- 半径边界位置与一阶变化连续；
- 抓取中心的位移与运动状态一致；
- Mask 红色通道乘入最终权重；
- 缺少 Mask 时权重为 `1.0`。

体积响应允许周围顶点产生与局部方向有关的剪切和体积联动。法线、切线与副切线由位移场 Jacobian 变换原始输入，随后重新正交化。

## Draw 与场景

- `StateIndex + ObjectID` 是运行时身份，不由显示名称决定。
- 数值型 Draw 使用明确的 index count、first index 和 base vertex。
- `drawindexed = auto` 使用调用时实际绑定的 VB/IB 和视图。
- 同一 Draw 的主体、轮廓、半透明和材质重绘必须读取同一状态。
- 只有场景主不透明主体参与鼠标候选选择。
- 每帧候选按有效性、场景 profile、可见深度、适配优先级和流水号确定唯一结果。

## 配置与迁移

`JiggleForge.txt` 是唯一可编辑项目配置。应用负责：

- 第一次导入时识别 Draw 并写入补丁；
- 再次打开时恢复或迁移配置；
- 将组和依赖图编译为状态索引列表；
- 为每个状态登记独立参数；
- 生成 Mask 与 Draw 检测器资源；
- 原地更新 Mod，同时保留原始绘制命令和条件结构。

旧 Schema 项目迁移到当前 Schema 前必须创建不可覆盖备份。

## 验收条件

- 全部 .NET 单元与契约测试通过；
- 正式 HLSL 入口以 Shader Model 5 编译；
- CPU 参考模型与 GPU 读回在容差内一致；
- 所有受支持 VS replacement 编译；
- 原版、适配 Mod、轮廓、半透明和近摄像机场景完成游戏内回归；
- 已登记早期参考实现的历史来源，并通过来源审计确认当前代码无完整文件匹配，也无参考实现特有的函数、状态布局或控制流残留。
